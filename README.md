### Descripción del proyecto

Aplicación de escritorio desarrollada en Python y Tkinter 
para gestionar clientes, servicios y reservas de Software FJ.

Implementa los principios de programación orientada a objetos
y manejo avanzado de excepciones, sin utilizar bases de datos.

### Funcionalidades

- Gestión de clientes.
- Gestión de servicios.
- Gestión de reservas.
- Confirmación y cancelación de reservas.
- Cálculo de costos, impuestos y descuentos.
- Validación de datos.
- Registro de eventos y errores.
- Simulación de operaciones.
- Pruebas unitarias.

### Conceptos de programación aplicados

- Abstracción.
- Herencia.
- Polimorfismo.
- Encapsulación.
- Métodos con parámetros opcionales.
- Excepciones personalizadas.
- Encadenamiento de excepciones.
- Manejo de listas y archivos.

### Requisitos

- Python 3.
- Tkinter.
- Visual Studio Code (opcional).

### Ejecución de la aplicación en Windows

    cd Software_FJ
    python aplicacion.py

### Ejecución de la simulación

    cd Software_FJ
    python main.py

### Ejecución de pruebas unitarias

    cd Software_FJ
    python -m unittest test_sistema -v

### GitHub Codespaces

La simulación y las pruebas unitarias pueden ejecutarse
directamente desde la terminal de Codespaces.

La interfaz gráfica Tkinter requiere un entorno de escritorio.

### Almacenamiento

La información se administra mediante objetos y listas en memoria.
El archivo eventos.log registra los eventos y errores del sistema.

No se utiliza ningún motor de bases de datos.
